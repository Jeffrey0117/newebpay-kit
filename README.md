# newebpay-kit

**藍新金流 NewebPay 零依賴 Node SDK:MPG 幕前支付 + 信用卡定期定額(建立/暫停/終止/改金額/查詢委託) + notify 解密驗章** 零依賴、框架無關。

## 安裝

```bash
npm i github:Jeffrey0117/newebpay-kit   # 或直接複製 index.js
```

## 用法

```js
const create = require('newebpay-kit');
const x = create({ /* opts */ });
```
